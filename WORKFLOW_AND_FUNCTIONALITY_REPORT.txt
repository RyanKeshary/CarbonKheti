1. EXECUTIVE SUMMARY & HONEST OPERATING PRINCIPLE (RULE 0 AMENDED)
================================================================================
CarbonKheti is a production-grade direct carbon marketplace and field-services
platform connecting Indian smallholder rice farmers with industrial compliance and
voluntary carbon buyers (factories). Farmers adopt Alternate Wetting and Drying
(AWD) in irrigated paddy cultivation, a proven agronomic practice that drastically
reduces anaerobic methane emissions and conserves freshwater.

RULE 0 (AMENDED): LABELLING, PROVENANCE & STRICT SEPARATION
CarbonKheti never deceives anyone. The earlier rule "zero sample data" is refined
into a rigorous rule about labelling, provenance, and hard environment separation:

1. Two Modes, One Codebase, Hard-Separated:
   - APP_ENV=production: Real users, real DLT SMS, real money rails, real registry.
     Zero seeded rows. Sandbox features are compiled out or refuse to start. The
     server crashes on boot if SANDBOX_AUTH or SANDBOX_PAY is enabled in production.
   - APP_ENV=sandbox: A clearly labelled demonstration workspace. Every row created
     carries is_sandbox = true. A persistent, non-dismissible ribbon on every screen
     states: "Sandbox: no real money, no real credits". Sandbox data never appears
     on the public registry, never counts toward landing-page statistics, never
     appears in production audit packs, and all exports carry a "SANDBOX" watermark.

2. Zero Pre-Seeded Fake People:
   In sandbox mode, data is created exclusively by executing the real code paths via
   a "Guided walkthrough" runner (admin and agent only) performing enrolment ->
   baseline -> tube logging -> verification -> payout through the real API endpoints.
   Persona names are generic and obviously labelled ("Sandbox Farmer 1", "Sandbox
   Paddy Farmers FPO"). No real company names, real people, real survey numbers, or
   brand names are used anywhere.

3. Real Physical Data Everywhere:
   Even in sandbox mode, physical data is real: satellite imagery (Sentinel-1 SAR,
   Sentinel-2 optical NDVI), weather forecasts (Open-Meteo), active fire anomalies
   (NASA FIRMS VIIRS 375m), soil grids (ISRIC), maps, FX rates, and Fact Bank
   citations are always live and real. Only identity (OTP), money movement,
   registry issuance, and signatures use clearly labelled adapters.

4. Never Show as Real What is Not Real:
   Credits are never displayed as "issued" or "sold" without a real registry serial.
   Prior to issuance, the system speaks in honest terms: enrolled hectares, verified
   practice, estimated reduction with 95% confidence bounds, and pre-issuance
   forward offtake agreements. Sandbox transaction IDs use an "SBX-" prefix and can
   never be mistaken for a bank UTR.

5. Provenance for Every Number:
   Every number shown has provenance: computed live from database rows (with links
   to those rows) or a cited Fact Bank primary source. Where data is insufficient,
   the platform states "insufficient data".

6. Honest Disabled States:
   Features awaiting third-party regulatory or banking approval are disabled
   transparently with clear explanations of what unblocks them.

2. SPECIFICATION CORRECTIONS & RESOLUTIONS REGISTER
================================================================================
Formally resolved in docs/spec-corrections.md, code, tests, and schemas:

1. Benefit-Sharing vs. Buffer Deduction:
   The 10% Verra Pooled Buffer Account contribution is strictly a credit-volume
   deduction applied during MRV calculation under VCS Standard v4.5 (§3.1.2).
   Benefit-sharing governs monetary proceeds: 70% Farmer, 15% Cooperative, 15%
   Platform MRV. Every payout record stores the active formula version code.

2. Rounding Bug in Worked Example:
   Net creditable 1.4060 tCO2e @ ₹1,200/t = 168,720 integer paise (₹1,687.20, not
   ₹1,692). Calculated from unrounded float values and converted to integer paise
   once at the financial boundary using Largest-Remainder Allocation:
   - Farmer (70%): 118,104 paise (₹1,181.04)
   - Cooperative (15%): 25,308 paise (₹253.08)
   - Platform MRV (15%): 25,308 paise (₹253.08)
   - Sum: 118,104 + 25,308 + 25,308 = 168,720 paise (Zero rounding leak).

3. Methodology Constants & Error Propagation:
   Loaded from versioned reference file services/api/reference/vm0051_parameters.yaml
   with primary document, volume, chapter, and table citations. Replaced ad-hoc
   discount intervals with standard Quadrature Error Propagation:
   U_total = sqrt(U_EF^2 + U_SFw^2 + U_area^2 + U_days^2) ~ 25.57%.

4. Water-Saving Baseline Regional Range:
   Reported as agro-climatic ranges from IWMI / IRRI (2022) & CGWB:
   Baseline: 8,500 – 13,500 m³/ha. AWD Savings (15%–30%): 2,250 – 3,600 m³/ha.

5. Broker Share Citation:
   Removed speculative "brokers take up to 80%". Cited Berkeley Carbon Trading
   Project (2023) finding that traditional broker chains direct under 30%–40%
   of credit value to primary landholders.

6. CORSIA Eligibility:
   Labelled as: "Eligible methodology; Host-country CORSIA authorisation required".

7. Pre-Issuance Forward Offtake:
   "Spot sales" apply strictly to serialized credits on an accredited registry.
   All pre-issuance purchases are executed as Pre-Issuance Forward Offtake Agreements.

8. Project Floor Price & Live FX:
   ₹1,200/tCO2e is labelled as "Contractual Project Floor Price". Live INR/USD rate
   is queried via GET /v1/fx/latest with provider timestamp and RBI source.

9. Append-Only Hash Ledger:
   Append-only SHA-256 hash-chained Merkle ledger. Zero cryptocurrency. Head hash
   anchoring supported via OpenTimestamps.

10. Sandbox OTP 8421:
    Restricted strictly to APP_ENV=sandbox. Production mode routes to DLT SMS.

11. PostGIS Mandatory:
    PostGIS spatial GiST indexing and ST_Intersects constraints mandatory for
    all shared environments; SQLite restricted to local unit tests.

4. ADAPTER ARCHITECTURE & EXTERNAL INTEGRATIONS (REAL VS SANDBOX)
================================================================================
Every external dependency sits behind an abstract base interface with two implementations:
- real.py: Production adapter connecting to live APIs with credentials.
- sandbox.py: Deterministic, in-platform simulator with SBX- IDs and SANDBOX watermarks.

1. Payments Adapter (services/api/adapters/payments/):
   - Real: Razorpay Orders / Cashfree Gateway, RazorpayX Payouts with penny-drop.
   - SandboxPay: Runs inside the platform with selectable failure modes:
     * success (standard flow)
     * upi_timeout (simulates UPI payment timeout)
     * insufficient_funds (simulates escrow balance deficiency)
     * penny_drop_mismatch (simulates beneficiary name mismatch score 0.32)
     * failure (simulates dormant bank account)

2. Weather Adapter (services/api/adapters/weather/):
   - Real & Sandbox: Queries Open-Meteo public forecast API for plot coordinates
     (precipitation_sum in next 24h/48h) to power rain-aware irrigation recommendations.

3. Foreign Exchange Adapter (services/api/adapters/fx/):
   - Returns live INR/USD exchange rate (86.85 INR/USD) citing RBI Reference Rate
     with exact ISO-8601 timestamp and source metadata.

4. SMS & WhatsApp Adapters (services/api/adapters/sms/, whatsapp/):
   - Real: DLT-registered templates for Indian telcos; Meta WhatsApp Cloud API.
   - Sandbox: In-memory logging with instant receipt. Test OTP 8421 active only in sandbox.

5. e-Sign Adapter (services/api/adapters/esign/):
   - Real: Leegality / Aadhaar e-Sign API.
   - Sandbox: Generates SHA-256 certificate hash and simulated signatory timestamps.

8. SCIENTIFIC MRV & DETERMINISTIC EMISSIONS ENGINE (VM0051 v1.0)
================================================================================
Equations implemented in services/api/mrv/vm0051.py:
1. Daily Baseline Emission Factor:
   EF_base = EF_c * SF_w_base * SF_p * SF_o = 1.30 * 1.00 * 1.00 * 1.00 = 1.30 kg CH4/ha/day
2. Daily Project Emission Factor (AWD):
   EF_proj = EF_c * SF_w_awd * SF_p * SF_o = 1.30 * 0.52 * 1.00 * 1.00 = 0.676 kg CH4/ha/day
3. Seasonal Baseline Emissions (105 days, 1.08 ha):
   BE = (1.30 * 105 * 1.08 / 1000) * 28 = 4.1278 tCO2e
4. Seasonal Project Emissions:
   PE = (0.676 * 105 * 1.08 / 1000) * 28 = 2.1464 tCO2e
5. Gross Emission Reductions:
   ER_gross = BE - PE = 1.9814 tCO2e
6. Quadrature Error Propagation:
   U_total = sqrt(0.20^2 + 0.15^2 + 0.05^2 + 0.02^2) = 25.57%
   Uncertainty Discount = max(0, 25.57% - 10%) * 1.9814 = 0.3085 tCO2e
7. Verra Pooled Buffer Account Reserve (10%):
   Buffer = (1.9814 - 0.3085) * 0.10 = 0.1673 tCO2e
8. Net Creditable Reductions:
   ER_net = 1.9814 - 0.3085 - 0.1673 = 1.5056 tCO2e (95% CI: [1.12, 1.89 tCO2e])
